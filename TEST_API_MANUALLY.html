Instructions

  1. Open your database and find a firebase_uid from the users table
  2. Paste that Firebase UID in the input box above
  3. Click "Test if User Exists" to verify the UID
  4. Click "Send Test Quiz Attempt" to test saving a quiz
  5. Check the response - if successful, you'll see an attempt_id
  6. Click "Get User's Quiz Attempts" to verify the data was saved
  7. Check your database tables: user_quiz_attempts and user_quiz_answers

Expected Result: If the API is working, you should see success messages and the attempt_id.

If it fails: Check the error message to see what's wrong (User not found, API key invalid, etc.)
